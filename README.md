# 🎓 Student Grading Management System

A Python-based **Student Grading Management System** with a **Tkinter GUI** and a backend for managing student records. The application allows users to add, update, delete, search, and analyze student performance while automatically calculating grades and storing data persistently in a CSV file.

---

## ✨ Features

- 📌 Add new student records
- ✏️ Update existing student details
- ❌ Delete student records
- 🔍 Search students by name or ID
- 📊 Automatic grade calculation based on marks
- 📈 View student performance and grade distribution
- 💾 Persistent storage using CSV
- 🖥️ User-friendly Tkinter GUI
- 🗂️ Backend separated from GUI logic for better maintainability

---

## 🛠️ Tech Stack

- **Language:** Python
- **GUI:** Tkinter
- **Data Handling:** Pandas
- **Storage:** CSV
- **IDE:** Jupyter Notebook / VS Code

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/student-grading-system.git
```

### 2. Navigate to the project

```bash
cd student-grading-system
```

### 3. Install dependencies

```bash
pip install pandas
```

Tkinter comes pre-installed with most Python installations.

---

## ▶️ Run the Project

Open the notebook and execute all cells:

```bash
jupyter notebook
```

or

```bash
jupyter lab
```

Run all cells to launch the Student Grading System GUI.

## 📋 Functionalities

### Add Student

- Enter student details
- Input marks
- Grade is calculated automatically

### Update Student

- Modify existing student information
- Changes are saved automatically

### Delete Student

- Remove student records permanently

### Search Student

- Find students quickly using their details

### Grade Calculation

| Marks | Grade |
|--------|-------|
| 90–100 | A |
| 75–89 | B |
| 60–74 | C |
| Below 60 | D |
